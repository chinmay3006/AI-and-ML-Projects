📺 YouTube Trending Analysis Dashboard
An interactive Data Analytics web application built using Python and Streamlit to explore trending patterns on YouTube. This project provides deep insights into video engagement metrics such as views, likes, and comment counts.

🚀 Features
Real-time Data Filtering: Filter analytics by specific YouTube channels to see their individual performance.

Key Performance Indicators (KPIs): Instant view of Total Views, Total Likes, and Video counts for the selected criteria.

Hall of Fame Section: Automatically identifies and displays:

👑 Highest Views: The most-watched video in the selection.

❤️ Highest Likes: The most-loved video based on engagement.

📉 Lowest Views/Likes: Insights into the least performing trending content.

Interactive Visualizations:

Top 10 Videos Bar Chart: Horizontal bar chart showing top videos by view count.

Engagement Scatter Plot: Analysis of the correlation between Views and Likes.

🛠️ Tech Stack
Frontend: Streamlit (Python-based web framework)

Data Manipulation: Pandas, NumPy

Visualizations: Plotly Express (Interactive Charts)

Environment: VS Code
