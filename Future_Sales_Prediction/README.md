# 📈 Future Sales Prediction

This project focuses on predicting product sales based on advertising budgets spent on TV, Radio, and Newspaper channels. It uses a Linear Regression model and provides an interactive dashboard via Streamlit.

## 📊 Project Overview
- **Goal:** To understand the relationship between advertising spend and sales.
- **Model:** Linear Regression.
- **Features:** TV, Radio, and Newspaper budget.
- **Target:** Sales.

## 🛠️ Tech Stack
- **Language:** Python 🐍
- **Libraries:** Pandas, NumPy, Scikit-Learn
- **Visualization:** Plotly
- **Web App:** Streamlit 🎈
